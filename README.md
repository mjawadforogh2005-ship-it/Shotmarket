📸 ShotMarket
Professional Photo Delivery & Marketplace Platform
ShotMarket is a modern web platform designed for photographers to upload, organize, share, sell, and securely deliver event photography through private digital galleries.

The project was created to solve a real problem faced by photographers: delivering large numbers of event photographs to customers in a simple, professional, and organized way.

ShotMarket connects photographers and customers through unique digital photo galleries that can be accessed using a gallery link or QR code.

🎯 Project Idea
ShotMarket creates a complete workflow between photographers and their customers.

A photographer can:

Create an event album
Add event information
Upload photographs
Organize photographs inside an album
Store photographs in cloud storage
Generate a QR code for the album
Share the gallery with customers
Provide payment information
Manage albums and photographs
A customer can:

Scan a photographer's QR code
Open a private photo gallery
View photographs
Preview photographs in a lightbox
Select photographs
Review the payment amount
View photographer bank information
Copy payment information
Confirm a simulated payment
Access purchased photographs for download
